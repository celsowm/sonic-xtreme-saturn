# Research and asset policy

Research leads (not approval or verified compatibility):
- Sonic X-treme prototype art and Jade Gully preservation: https://models.spriters-resource.com/saturn/sonicxtreme/
- Sonic Jam: https://models.spriters-resource.com/saturn/sonicjam/
- Sonic Z-Treme: https://github.com/Maxime-XL2/SONIC-Z-TREME
- Sonic Adventure behavior/reference: https://github.com/reshaped/sonic-adventure
- SA tooling: https://github.com/X-Hax/SonicAdventureBlenderIO
- Sonic GT and Sonic World DX: level-design references.

Availability online is not permission to redistribute. No new unrelated proprietary art, code, music, ROMs, BIOS or unlicensed models should be committed. Source code and gameplay should be independently authored. The repository owner **explicitly requested** versioning the Sonic R model supplied through chat; its bytes, conversion and SHA-256 provenance are recorded in [assets/sonic-r/ATTRIBUTION.md](../assets/sonic-r/ATTRIBUTION.md). The original ZIP contains no license file, and redistribution permission still needs verification. The code license does not grant rights to the model or Sega characters. If the license is incompatible with public sharing, the owner must remove the asset from Git history and host it in an appropriately restricted repository. For other assets, record author, URL, retrieval date, hashes, exact license and allowed uses. Do not scrape or bypass protections. No linking GPL components without an explicit license/architecture decision.

## Curated CC0 scenery actually versioned

Nine **Kenney** low-poly GLBs are now tracked at [`assets/kenney/`](../assets/kenney/ATTRIBUTION.md), including palm trees, bushes, rocks, a waterfall cliff, a wooden bridge, grass platform and temple wall pieces. Both Kenney's [Nature Kit](https://kenney.nl/assets/nature-kit) and [Castle Kit](https://kenney.nl/assets/castle-kit) identify as CC0; the converted GLB mirror also declares these derivatives CC0. The repo records the original pack links, mirror, per-file Git hashes and conversion limitations. These are unrelated to the unverified redistribution status of the Sonic R model. The current adventure builder imports selected models for **authoring only** and decimates them to strict face budgets; it does not dynamically load GLB on target.

Further candidate research, not yet committed: Quaternius [Ultimate Nature](https://quaternius.com/packs/ultimatenature.html) and [Ultimate Modular Ruins](https://quaternius.com/packs/ultimatemodularruins.html), also offered CC0. Do not bulk import packs into a single Saturn scene.
